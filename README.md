# Arduino Potentiometer & Python Project

Чтение данных с потенциометра на Arduino и визуализация в Python.

## Оборудование
- Arduino Uno
- Потенциометр (10 кОм)
- Соединительные провода
- Макетная плата

## Схема подключения

https://github.com/mariakuleshina-cmyk/Arduino-Potentiometer-Python/blob/15f93b2fc50d7bbb2e10ab046b52eee23af1e549/wiring.png

## Функциональность
1. Arduino считывает значение с потенциометра каждую секунду
2. Передаёт данные через Serial (9600 бод)
3. Python читает 100 значений и строит график
